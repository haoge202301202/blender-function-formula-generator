# 函数公式生成器（Function Formula Generator）— Blender 5.2+ 插件

用数学公式直接生成三维函数图像：**曲线圆管 / 曲面网格 / 参数曲线 / 参数曲面**。
自带**一键渲染预览**、**批量公式**，并在**几何节点**里提供「函数公式节点」（公式编译成节点，可在修改器里调参）。
材质统一使用 **Blender 原生材质**，在 **Shader Editor（着色器）** 里编辑；插件只保留新建/套色/应用等快捷操作。

- 版本：**v1.5.0**
- 实测环境：**Blender 5.2.0 LTS**（Windows x64，内置 Python 3.13）
- 插件形态：legacy 插件（含 `bl_info`），支持 Blender 自带的「从磁盘安装…」
- 插件目录：`function_formula_gen/`；安装包：`function_formula_gen-1.5.0.zip`

---

## 1. 安装

### 方式 A：从 ZIP 安装（推荐，一次装好并自动启用）

1. 打开 Blender → **编辑(Edit) → 偏好设置(Preferences)**；
2. 左侧选 **插件(Add-ons)**（5.2 中「扩展」页也能装，效果一样）；
3. 点搜索栏右侧 **▾ 下拉箭头 → 从磁盘安装…(Install from Disk…)**；
4. 选择本目录下的 `function_formula_gen-1.5.0.zip`，确认；
5. 安装后默认自动勾选启用（若没有，在插件列表搜索「函数公式生成器」勾选）；
6. 回到 3D 视图按 **N**，侧栏出现 **「函数生成」** 标签页。

> 提示：当前这台电脑上的 Blender 5.2 已经安装本插件；**更新版本后需要重启 Blender**
> （或在插件列表里禁用再启用）才会加载新代码。

### 方式 B：手动复制

把 `function_formula_gen` 整个文件夹复制到：

    %APPDATA%\Blender Foundation\Blender\5.2\scripts\addons\function_formula_gen

重启 Blender，在偏好设置 → 插件里搜索并勾选「函数公式生成器」。

## 2. 快速上手

1. 3D 视图按 **N** → 切到 **「函数生成」**；
2. 生成模式选 **曲线圆管 (Tube)**，公式 `sin(x) * 2`，点 **「生成」**；
3. 换 **曲面网格 (Surface)**、公式 `sin(x) * cos(y) * 2`，再点生成；
4. 换 **参数曲线 (Param Curve)**：`x(t)=cos(t)`、`y(t)=sin(t)`、`z(t)=t / 3`，
   范围 0 ~ 12.566，点生成得到螺旋线；
5. 换 **参数曲面 (Param Surface)**：环面公式
   `x=(2 + cos(v)) * cos(u)，y=(2 + cos(v)) * sin(u)，z=sin(v)`，
   U 范围 0 ~ 6.283，V 范围 0 ~ 6.283，点生成得到彩色环面；
6. 点 **「渲染预览」** 一键自动取景打光出图。

「示例公式」菜单里有 13 个内置示例（含批量对比、螺旋线、球面、环面、莫比乌斯带…），可以一键填入。
公式框右侧的 **⌨** 按钮会打开 **Desmos 风格数学键盘**，键盘上有 x/y/π/√/|a|/数字/运算符等按键，可移动光标、退格、插入函数；
公式框里也可以直接用 Desmos 写法手打（例如 `2x^2+sin(πx)`）。

## 3. 生成模式与参数

| 模式 | 公式变量 | 说明 |
| --- | --- | --- |
| 曲线圆管 (TUBE) | x, y（两者都等于采样参数） | 沿 Y 轴路径，Z = f(x)，曲线 Bevel 生成圆管，两端封口并焊接成水密网格 |
| 曲面网格 (SURFACE) | x, y | XY 平面网格 + 公式高度，四边形面、平滑着色 |
| 参数曲线 (PARAM_CURVE) | t | x(t), y(t), z(t) 三个公式生成任意空间曲线管（螺旋线、结等） |
| 参数曲面 (PARAM_SURFACE) | u, v | x(u,v), y(u,v), z(u,v) 三个公式生成真三维曲面（球面、环面、莫比乌斯带） |

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 公式 | sin(x) * 2 | 数学表达式，旁边 **ƒ 按钮**可以点选函数/变量/运算符追加 |
| 附加公式 | 空 | 高度场模式的批量列表：一次生成多个不同物体（每条公式一个物体） |
| 采样范围 | -5 ~ 5 | 参数曲面有 U、V 两组范围 |
| 分辨率 | 100 | 分段数（曲面顶点数 = (分段数+1)²） |
| 自动加密采样 | 开 | **v1.1 修复大范围曲线抖动**：范围越大自动增加采样点；小范围保持你设置的分辨率不变 |
| 管道半径 | 0.1 | 圆管类模式生效 |
| 无定义点处理 | 自动容错 | `1/x` 在 x=0、`log(0)` 等：曲线自动断开成多段、曲面用邻近值填充；可切「严格报错」 |
| 自动彩色材质 | 开 | 着色依据（高度 Z / 到中心距离 / 单色）+ 4 套色带 |
| 预览引擎/尺寸/采样 | 跟随场景 / 960x720 / 32 | 一键渲染预览参数 |

## 4. 公式语法

- **变量**：`x`、`y`（高度场）；`t`（参数曲线）；`u`、`v`（参数曲面）
- **常量**：`pi`、`e`、`tau`
- **运算符**：`+ - * / // % **`、一元 `+/-`、比较、条件表达式、`and / or / not`
- **函数**：`sin cos tan asin acos atan atan2 sinh cosh tanh exp log ln log2 log10 sqrt pow hypot abs floor ceil round trunc sign min max clamp degrees radians`
  也支持 `math.sin(x)` 前缀写法。
- **Desmos 风格写法（v1.2 新增）**：
  - 幂：`x^2`（等价 `x**2`）；
  - 隐式乘法：`2x`、`2(x+1)`、`(x+1)(x-1)`、`2sin(x)cos(x)`、`pi x`；
  - 符号：`π`、`√x`、`√(x+1)`、`|x|`、`≤`、`≥`、`≠`、`×`、`÷`；
  - 等式前缀：`y = sin(x)`、`z = x^2 + y^2`、`f(x) = 2x + 1` 会自动只取右边表达式；
  - 全角字符/中文输入法符号（×、÷、−、π、≤…）也能识别。

**示例**

| 公式 | 模式 | 效果 |
| --- | --- | --- |
| `sin(x) * 2` | 圆管 | 正弦曲线圆管 |
| `sin(x) * cos(y) * 2` | 曲面 | 水波纹 |
| `5 * sin(sqrt(x*x + y*y)) / (sqrt(x*x + y*y) + 0.001)` | 曲面 | 墨西哥草帽 |
| x=cos(t), y=sin(t), z=t/3 | 参数曲线 | 螺旋线 |
| x=(2+cos(v))*cos(u), y=(2+cos(v))*sin(u), z=sin(v) | 参数曲面 | 环面 |
| x=sin(u)*cos(v), y=sin(u)*sin(v), z=cos(u) | 参数曲面 | 球面 |

### 安全性

1. **AST 白名单校验**：只允许数学运算、白名单函数/常量、当前模式变量；属性访问仅 `math.xxx`；
   下标/lambda/推导式/字符串/import/赋值等全部拒绝；
2. **受限 eval**：`{"__builtins__": None, "math": math, "x": x, "y": y}` 再注入白名单函数/常量，
   拿不到 `open` / `__import__` 等能力；
3. 常量折叠安全检查：`10 ** 400`、`2 ** (2 ** 20)` 等在构造阶段就报错；
4. 长度/AST 节点数/幂指数/结果大小上限，除零/定义域/NaN/Inf 都有清晰提示。

## 5. 函数输入：数学键盘 + 函数模块（Desmos 风格）

v1.2 把公式输入改成了 Desmos 风格：

- 每个公式框右侧两个按钮：
  - **⌨ 数学键盘**：打开 Desmos 风格键盘（变量 / 数字 / `+ − × ÷` / `( )` / `x²` / `xʸ` / `π` / `√` / `|a|` / `≤ ≥` / 功能菜单 / ← → / ⌫ / C / 完成）；
  - **ƒ 函数模块**：快速插入函数名（不用打开键盘）。
- 键盘维护自己的**光标位置**：
  - 数字/变量在光标处插入；点 `x²` 插入 `^2`、`xʸ` 插入 `^`；
  - 点 `√` / `|a|` 会插入 `sqrt()` / `abs()` 并把光标放到括号里；
  - 点 `+ − × ÷ ≤ ≥` 这类二元运算符时会自动跳过光标右侧的 `)`；点 `)` 时如果右侧已经有 `)` 就直接跳过；
  - ←/→ 移动光标，⌫ 退格（删除一对空括号）、C 清空、完成 关闭键盘；
  - 键盘编辑时上方会实时显示"带光标的公式"，例如 `2x^2 + sin(πx)|`。
- 公式框本身仍然可以直接手打（支持上面第 4 节的 Desmos 写法），两种方式可以混用；
- 「功能」按钮打开函数分类子菜单（三角函数 / 指数对数 / 取整符号 / 其它函数 / 运算符）。

## 6. 材质：统一放到 Blender 着色（Shader Editor）里管理

v1.5 起，**静态生成的物体和几何节点物体都用普通 Blender 材质**，材质就在物体材质槽里，
在 **Shader Editor（着色器编辑器）** 里随便改颜色、贴图、发光、节点，插件不会再偷偷重建/覆盖。

面板「外观 / 材质」只保留快捷操作：

- **统一材质**：选一个已有 Blender 材质，之后新生成的物体都用它（几何节点物体写进节点组「材质」输入）；
- **新建材质**：按下面「快捷颜色」创建一份普通 Blender 材质（Object 坐标 → Map Range → ColorRamp → Principled BSDF），
  自动放进物体材质槽，之后在 Shader Editor 里继续编辑；
- **套用颜色**：把「快捷颜色」里的颜色套到当前材质的 ColorRamp 上（**只改颜色，不重建节点**，其它着色节点保留）；
- **应用到选中**：把「统一材质」应用到选中的本插件物体；
- **着色器**：一键打开 Shader Editor 并定位到当前材质（没有着色器窗口时自动新建一个）；
- **物体材质→节点组**：自建物体 + 插件几何节点组时，把物体材质写进节点组的「材质」输入；
- **用选中物体材质**：把选中物体的材质设为「统一材质」。

**快捷颜色**（新建/套用材质时使用）：着色依据（高度 Z / 到中心距离 / 单色）+ 色带
（彩虹/冷暖/单色渐变/海洋/自定义颜色）；「自定义颜色」可以增删色标、点颜色块取任意颜色、调位置。
这些颜色只是**快捷生成/套色**用，不是运行时自动同步——想改色请直接编辑材质，或点「套用颜色」。

> 默认行为：生成时如果物体还没有材质，才自动创建一份；已有材质不会被覆盖。
> 想让所有物体共用一个材质：在「统一材质」里选同一个材质，再对已有物体点「应用到选中」。

## 7. 一键渲染预览

- 点 **「渲染预览」**：自动创建/复用预览相机和三点灯光，按物体包围盒自动取景，
  渲染完成后**自动在 Blender 图片编辑器里打开**（没有图片编辑器时会新开一个预览窗口，
  类似 F11 的渲染窗口，不需要自己去文件夹里翻图）；
- 面板有 **「打开预览图」** 按钮可随时重新打开上一次的预览图；
- 引擎可选「跟随场景 / EEVEE / Cycles(CPU)」，尺寸/采样可调；
- **不会改动场景设置**（渲染完恢复原来的引擎/相机/世界/分辨率）；预览相机/灯光放在
  「函数图像·预览」集合里并在视口隐藏，不挡模型。
- EEVEE 在无 GPU 的 headless 环境失败时会自动降级到 Cycles CPU。

## 8. 几何节点（Geometry Nodes）

### 8.1 在 Add 菜单插入新节点

几何节点编辑器按 **Shift+A** → 菜单底部 **「函数公式节点」**：
对话框按模式输入公式（参数模式 3 个），确定后生成节点组并插入当前树，
Group Output 空闲时会自动连接。节点组内部：

- 高度场曲面：Grid → Map Range → 公式 Math 节点链 → Set Position → Set Shade Smooth；
- 高度场圆管：Mesh Line → Map Range → 公式链 → Set Position → Mesh to Curve → Curve to Mesh（Fill Caps）；
- 参数曲线/曲面：Mesh Line(t) 或 Grid(u,v) → 三条公式链 → Set Position →（圆管）Curve to Mesh；
- 节点组内也带**自动加密采样**逻辑，大范围时同样自动增加采样点；
- 参数曲面的接缝用 Merge by Distance 节点自动焊接。

### 8.2 生成几何节点物体

3D 侧栏「几何节点版本」或节点编辑器侧栏 → **「生成几何节点对象」**：
生成带 NODES 修改器的物体，可在修改器面板直接调 **范围 / V 范围 / 分辨率 / 半径**，
批量公式也会生成多个几何节点物体。

**颜色/材质（v1.5）**：几何节点物体同样使用普通 Blender 材质。节点组新增 **「材质」输入**（Material 类型），
内部用 Set Material 节点写到几何体上：
- 插件生成的几何节点物体：自动用物体材质/统一材质，材质在 Shader Editor 里改；
- 自己新建物体 + 插件节点组：在修改器里把「材质」选成你的材质，或点面板「物体材质→节点组」；
- 之后颜色/贴图/发光全在 Shader Editor 里管理，插件不会覆盖。

**节点组输入（v1.3 扩展）**：节点组接口现在外露了这些参数，生成后可直接在修改器里调，
也可以在节点编辑器里连字段/动画：
- **材质**（Material 输入，Set Material 写到几何体上）；
- 范围起始 / 结束、分辨率、管道半径（圆管）；
- 自适应加密、平滑着色、输出属性（函数值/参数属性）；
- 坐标缩放、位置偏移（整体变换）；
- 截面边数、封口（圆管）；
- 接缝焊接（参数曲面）；
- **参数 a、b、c、d**：公式里的系数；在修改器里改数值、加关键帧/驱动器，
  或在节点编辑器里把「场景时间 / 噪声 / 编号」等字段连到参数输入，就能让系数随空间或时间变化。
  （例：公式 `a*sin(x)`，把噪声纹理的 Fac 连到「参数 a」，振幅就会随位置起伏。）

**函数场节点（v1.3 新增）**：把公式变成可在任意几何节点树里复用的"字段"：
- 「函数值场（x,y→值）」：输入 Position，输出公式值，可拿去做位移/选择/实例化；
- 「曲线向量场（t→xyz）」/「曲面向量场（u,v→xyz）」：输入参数，输出位置向量。
- 入口：几何节点编辑器的 **Add 菜单 > 函数场节点**，或侧栏「函数场节点」按钮组；
  公式在插入时烘焙，改公式后点「更新节点树里的函数场」重建；
- 场节点的 a-d 参数同样可以连噪声/场景时间等字段。

**参数实时同步（v1.2）**：选中自己生成的几何节点物体后，在面板里改公式或参数会**自动同步**：
- 公式 / 模式变化 → 自动重建节点组（物体、修改器、材质保留）；
- 范围 / V 范围 / 分辨率 / 半径 → 自动更新修改器输入；材质只在缺省时补齐，不覆盖用户材质；
- 同步约 0.5 秒防抖执行，可在「高级选项 → 几何节点参数实时同步」关闭；
- 「更新选中物体」按钮对几何节点物体也可用（立即同步）；

## 10. 已知限制

- 曲面分辨率 N → 每边 N+1 个顶点；大范围时自动加密上限：曲线 8000 段、曲面 512 段；
- 曲线控制点之间用 Bezier 自动手柄平滑：默认/加密后与公式误差极小（<1e-5），
  关闭「自动加密采样」并配合大范围时误差会变大（v1.0 的抖动问题）；
- 圆管两端用曲线 `use_fill_caps` 封口，插件会把端盖与管身重合点焊起来得到水密网格；
- 参数曲面「焊接接缝」适合球面/环面等首尾重合的曲面；接缝不重合的曲面请关闭；
- 几何节点版本对除零按 Blender 数学节点语义处理（返回 0），不会断开曲线；静态生成才有容错/严格两种模式；
- 几何节点版本的公式/场节点公式是烘焙在节点组里的；改公式后对象靠面板同步重建，
  函数场节点需点「更新节点树里的函数场」重建；
- 几何节点版本里参数 a-d 是节点输入（不是每点独立随机），要空间变化可连噪声等字段；
- 材质/颜色设置（自定义颜色列表、当前材质）不随单个物体保存；材质本身已生成在物体上并保留。
  「读取参数」不会恢复自定义色标列表；
- 默认每个物体一份自动材质；要统一使用同一材质，请在「统一材质」里选材质并「应用到选中」；
- 改颜色不再自动重建材质：改面板颜色后需点「套用颜色」，或者直接在 Shader Editor 里改；
- 公式里 `y = …` / `z = …` / `f(x) = …` 会自动去掉左边；`x = 1` 这类不支持（会当语法错误提示）；
